# samples

Put test clips here. Video files in this folder are ignored by git, so real
footage never ends up in the repository.

Good test clips from the Sep 20 2026 session (in Downloads/SSAC Videos):

- IMG_6073 to IMG_6080: dive camera, above water, side on
- IMG_8079 to IMG_8144: side camera, whole lap (25 yd), both walls in view
- IMG_5956 to IMG_6006: front corner camera

To get a cartoon clip before real footage is ready:

    python tools/make_sample_clip.py

which writes samples/synthetic_sprint.mp4 (a cartoon of one length).
